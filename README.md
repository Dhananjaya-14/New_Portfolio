# Dhananjaya Bulumulla — Portfolio

A responsive, single-page portfolio presenting Dhananjaya's software engineering and UI/UX design experience.

## Preview

Open `index.html` in a browser. The site is self-contained and has no package installation or build step.

## Deploy

Publish the repository root with a static hosting provider such as GitHub Pages, Vercel, or Netlify. Keep the two CV PDFs in the root so the download links continue to work:

- `Dhananjaya_Bulumulla_Software_Engineer_CV.pdf`
- `Dhananjaya_Bulumulla_UI_UX_Designer_CV.pdf`

## Customize

Edit `index.html` to update the profile, projects, skills, education, contact details, or visual styles.
